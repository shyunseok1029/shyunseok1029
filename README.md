# Security Engineering

웹·인프라 모의해킹을 중심으로 공부하고 있습니다. 웹 서비스와 시스템의 구조를 이해하고, 취약점이 어떤 공격 경로로 이어지는지 분석하는 데 관심이 있습니다.

## About Me

정보보안공학을 전공하며 웹·시스템 보안, 네트워크, 보안 프로젝트를 중심으로 학습하고 있습니다. 장기적으로 클라우드 보안과 레드팀 분야로 관심을 넓혀가는 것이 목표입니다.
