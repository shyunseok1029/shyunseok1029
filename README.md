# 박현석 (Hyunseok Park)

상명대학교 정보보안공학과 학부생이며, 웹, 인프라 모의해킹을 중심으로 공부하고 있으며 장기적으로 클라우드 보안과 레드팀 분야로 취업을 준비하고 있습니다

## Areas of Interest

- **Web Security** — 웹 애플리케이션 구조와 취약점 분석
- **Attack Path Analysis** — 취약점 간 연결과 공격 경로 분석
- **Cloud Security** — 컨테이너와 Kubernetes 보안에 대한 관심

## Team Projects

- **[CTF-OS](https://github.com/whatevertakes/CTF-OS)** (WT 조직 팀 프로젝트): Python 기반으로 CTF 문제의 관리·실행과 분석을 지원하는 프로젝트입니다. CLI, Linux / WSL2, Docker sandbox 환경을 사용하며 Managed / Assisted 실행 방식을 제공합니다.

- **MCP Tool Composition Security** (팀 연구 · 진행 중): Python, Docker, uv, pytest 환경에서 다중 MCP 도구 조합의 위험 경로를 분석하고 실행 통제를 평가하는 캡스톤 연구입니다. 연구 완료 전에는 확정된 결과나 저장소 링크를 추가하지 않았습니다.

- **WhiteHat School Kubernetes Security Project** (화이트 햇 스쿨 4기) : 화이트 햇 스쿨 4기 팀 프로젝트 기간에 진행한 Kubernetes, EKS, AWS 등의 환경에서 수행한 레드티밍 내용을 담았습니다.

## Personal Projects
